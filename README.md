# 日常视频提取器（抖音 / 快手 / B站）
输入指定用户的抖音、快手或 B站主页链接，按日期筛选作品并批量下载；也可以直接粘贴抖音、快手、B站的单个视频链接（含分享文案和短链），单独提取一个或多个视频。B站支持多P；下载默认走原始流，可选 1080P/4K 原画。界面为双标签页卡片布局，读取默认在后台完成，不弹出浏览器窗口。

## 支持平台

- 抖音作者：`https://www.douyin.com/user/MS4wLjAB...`
- 快手作者：`https://www.kuaishou.com/profile/3x...`
- B站作者：`https://space.bilibili.com/123456/video`
- 抖音单个视频：`https://www.douyin.com/video/七千...`、`https://v.douyin.com/xxxx/`
- 快手单个视频：`https://www.kuaishou.com/short-video/3x...`、`https://v.kuaishou.com/xxxx`
- B站单个视频：`BV1xx411c7mD`、`av170001`、`https://www.bilibili.com/video/BV...`、`https://b23.tv/xxxx`

快手作者页和快手单视频读取需要登录态，会先关闭一次本机浏览器，然后在后台无窗口读取；B站和抖音使用独立配置，不会关闭你正在用的浏览器。B站作者页会自动点击“下一页”；作者页列表中的多P稿件仍按 P1 下载，要提取全部分P请用“视频链接”标签页并勾选“B站多P提取全部分P”。

> 仅供个人学习、备份自己的作品或经授权内容使用。请遵守各平台用户协议、版权和隐私规定；不要批量抓取、传播或商用他人内容。本工具不内置账号、Cookie 或任何媒体文件。

## 功能

- 双标签页：`UP主主页` 读取作者全部投稿；`视频链接` 解析抖音 / 快手 / B站 单个视频
- 用户主页 URL、分享链接或 `sec_uid`
- 日期筛选：今天、昨天、近 7 天、全部、自定义
- 作品列表、批量下载、实时进度、取消任务
- 后台读取：B站 / 抖音使用独立配置无头运行，不弹出窗口，也不关闭你正在用的浏览器
- B站作者页自动翻页（可关闭），支持最大翻页数保护
- 三平台视频链接批量解析：完整链接、分享文案、短链、BV / av 号
- 多P视频：默认取 P1，可用 `?p=2` 指定分P，也可一次提取全部分P
- B站原画：有登录 Cookie 时下载 1080P/4K DASH 原始流并自动合并音视频（需 ffmpeg）
- 支持普通视频、图文相册、实况照片（Live Photo）
- 图文作品保存为图片序列；实况照片同时保存图片和短视频
- 不再把图文的背景音乐误存成视频
- 下载目录：作者模式为 `用户昵称_sec_uid后8位/YYYY-MM-DD/`，链接模式为 `视频链接/平台/作者/YYYY-MM-DD/`
- `.part` 临时文件、历史去重、每条视频 `.json` 元数据、`metadata.json`
- 浏览器模式直接使用你平时的 Edge/Chrome 登录状态

### 后台读取

- B站和抖音默认使用独立浏览器配置，加 `--headless=new` 在后台加载页面，不会出现浏览器窗口，也不会关闭你正在用的 Edge/Chrome。
- B站首次使用独立配置时会先访问一次 B站首页预热 Cookie，再进入空间页，避免新配置触发风控。
- 后台模式失败时会自动降级：无头 → 屏幕外窗口 → 可见窗口，日志里会说明当前模式。
- 快手必须使用登录态：程序会先关闭一次浏览器，再用同一配置无头读取，读取完成后退出。
- 快手读取过程中如果需要登录或安全验证，仍可能弹一次可见窗口让你完成验证。

### 快速读取

- 直接的用户链接会在本地识别，跳过资料预请求。
- 每次作品接口返回后立即继续滚动，不再固定等待 1.2 秒。
- 接口明确返回“没有更多”后约 0.25 秒结束。
- 选择今天、近 7 天等日期范围时，一旦读到范围之前的作品就提前停止。
- B站空间页会识别分页按钮并自动点击“下一页”，直到没有更多或达到最大页数。
- B站分页读取的等待时间比抖音/快手更长，避免翻页请求还没返回就提前结束。
- Windows 进程检测改用系统 API，减少启动、关闭浏览器时的等待。
- 浏览器启动后会检查本地读取组件的实际连接状态，避免“网页打开但组件未加载”。
- 如果 Edge 的启动加速复用了无扩展的后台进程，程序会自动关闭并重试，共最多 3 次。

## 环境要求

- Windows 10/11
- Python 3.10+（官方 Windows 安装包默认包含 Tkinter）
- 可选：`imageio-ffmpeg`（B站 1080P/4K 原画合并需要；打包脚本会自动安装并内置）
- 可选：PyInstaller（仅打包 exe 时需要，由 build.bat 自动安装；日常运行不需要）

运行源码时如需 B站原画：

    python -m pip install imageio-ffmpeg

没有 ffmpeg 时会自动退回 720P MP4，不影响其他功能。

## 快速开始

1. 安装 Python 3.10+，安装时勾选 Add python.exe to PATH。
2. 双击 run.bat，或执行：python douyin_daily.py
3. 在浏览器打开目标用户主页，复制地址栏链接，例如：
   https://www.douyin.com/user/MS4wLjAB...
4. 粘贴到工具中，选择日期，点击读取作品。
5. 勾选使用本机浏览器登录态。程序会使用你平时 Edge/Chrome 的登录状态；如果浏览器已经打开，会询问是否关闭并重启一次。

### 视频链接模式（抖音 / 快手 / B站）

如果只想下载某个视频，或作者页翻页太多，可以切到 `视频链接` 标签页：

1. 粘贴一个或多个链接，每行一个；也可以直接粘贴分享文案，程序会自动提取其中的链接，例如：
   - `https://www.douyin.com/video/...`、`https://v.douyin.com/xxxx/`
   - `https://www.kuaishou.com/short-video/3x...`、`https://v.kuaishou.com/xxxx`
   - `https://www.bilibili.com/video/BV1xx411c7mD`、`https://b23.tv/xxxx`、`BV1xx411c7mD`、`av170001`
2. B站需要指定分P时在链接末尾加 `?p=2`；想一次拿全部分P，勾选“B站多P提取全部分P”。
3. 点击解析链接，选择需要的作品后下载。
4. B站链接使用公开接口，不需要浏览器；抖音链接用无头浏览器读取页面数据；快手链接需要登录态，首次会提示关闭一次浏览器。
5. 链接模式按 `视频链接/平台/作者/日期/` 分目录保存。

### 浏览器读取方式

程序会在本机启动一个临时读取桥（只监听 127.0.0.1，其他设备无法访问），并通过一个临时 Edge/Chrome 扩展，读取抖音、快手或 B站页面自己请求的作品接口。

- B站 / 抖音：使用独立的浏览器配置，无头运行，不弹出窗口，也不会关闭你正在用的 Edge/Chrome
- 快手：使用本机登录态，需要先关闭一次浏览器，然后无头读取
- B站空间页会自动点击分页按钮，读取全部可访问的投稿页
- 不复制密码、书签或浏览历史
- 读取到的数据只发送到本机程序，不上传外部服务器
- 后台读取结束后会自动退出本次启动的浏览器实例

如果后台模式没有读到数据，程序会自动降级为屏幕外窗口或可见窗口；日志里会显示当前尝试的模式。需要排错时，可以取消勾选“后台读取（不弹窗口）”。

快手读取时如果页面要求登录或安全验证，程序可能显示一次浏览器窗口，请在该窗口完成验证后继续。

### Edge/Chrome 已经打开怎么办？

点击读取作品后选择 "是"，程序会自动关闭并重新打开浏览器一次；原来的标签页一般会自动恢复。

如果提示无法关闭，请按 Ctrl+Shift+Esc 打开任务管理器，结束所有 msedge.exe 或 chrome.exe 进程；或在浏览器菜单中完全退出后重试。

### 只有抖音号怎么办？

抖音号不能稳定地直接转换成 sec_uid。请先在浏览器打开该用户主页，复制地址栏完整链接再粘贴。

## 命令行用法

平台参数：`--platform auto|douyin|kuaishou|bilibili`。
快手和 B站作者页必须加 `--browser`；抖音模式下 `--browser` 推荐但不强制。视频链接模式用 `--links`。

B站作者页默认会自动翻页；如需手动翻页，可加 `--no-bili-auto-page`。后台读取默认开启，加 `--no-background` 可显示浏览器窗口。

三平台单视频链接：

    python douyin_daily.py --links "https://www.douyin.com/video/7698703113713465258" --download --out "D:\视频下载"

    python douyin_daily.py --links "https://www.bilibili.com/video/BV1xx411c7mD" --download --out "D:\视频下载"

多个链接可以写在同一段文本里（空格或换行分隔），程序会自动识别平台。B站原画默认开启，加 `--no-bili-original` 可只用 720P MP4；多P加 `--split-parts`。

抖音：

    python douyin_daily.py --url "https://www.douyin.com/user/MS4wLjAB..." --platform douyin --date today --browser --download --out "D:\视频下载"

快手：

    python douyin_daily.py --url "https://www.kuaishou.com/profile/3x..." --platform kuaishou --date 7days --browser --restart-browser --download --out "D:\视频下载"

B站：

    python douyin_daily.py --url "https://space.bilibili.com/123456/video" --platform bilibili --date all --browser --download --out "D:\视频下载"

只列出作品时去掉 `--download`。`--date` 支持：`today`、`yesterday`、`7days`、`all`、`YYYY-MM-DD`。

## 已知限制

- 抖音不是公开稳定 API，接口和风控随时可能变化。
- B站作者页依赖页面结构；如果 B站改版导致分页按钮变化，自动翻页会退化为手动翻页，日志里会提示。
- 视频链接模式支持普通投稿视频；暂不支持番剧、课程、直播回放和需要付费/DRM 的内容。
- 快手单视频和快手作者页都需要登录态；本机浏览器运行时 Cookie 库被独占，必须先关闭浏览器。
- 抖音单视频依赖无头浏览器加载页面，通常需要 5–10 秒；页面要求登录或验证时会失败。
- B站 1080P/4K 原画需要登录 Cookie 和 ffmpeg；未登录时最高 720P。
- B站作者页稿件列表中的多P视频仍按 P1 下载；需要全部分P时请用视频链接模式。
- 不绕过登录、付费、隐私或访问权限。
- 私密作品、仅粉丝可见、已删除作品无法获取。
- 直播、付费内容、私密作品不在下载范围内。
- 无水印取决于接口实际返回地址；平台台标通常是网页播放器浮层，不会写进文件，但 UP 主自己烧录的水印无法无损去除。
- 请控制请求频率和下载量。

## 详细使用说明

### 1. 启动

推荐使用打包版，不需要安装 Python：

    dist\DouyinDailyExtractor\DouyinDailyExtractor.exe

也可以双击项目根目录的 run.bat，它会自动优先启动打包版。

请保留整个 dist\DouyinDailyExtractor 文件夹，不要只单独移动 exe。

### 2. 获取目标用户链接

在浏览器打开抖音网页版，进入目标用户主页，复制地址栏链接。链接通常形如：

    https://www.douyin.com/user/MS4wLjAB...

也支持能跳转到用户主页的分享链接。只有抖音号或昵称时，请先手动打开其主页再复制链接。
### 3. 获取作品

1. 把用户链接粘贴到用户链接输入框。
2. 选择下载目录。
3. 选择日期：今天、昨天、近 7 天、全部或自定义。
4. 勾选使用本机浏览器登录态（推荐）。
5. 点击读取作品。
6. 作品会显示在下方列表。

### 4. 浏览器模式

- 程序会直接调用本机已安装的 Edge/Chrome，打开你平时使用的浏览器窗口。
- 会在该浏览器中临时加载一个本地读取组件，等待抖音页面自己请求作品接口，再把结果发回工具。
- 本地读取组件只连接 127.0.0.1，读取到的数据不会上传到外部服务器。
- 因此可以直接复用你浏览器里已有的抖音登录、关注和可见权限。
- 如果 Edge/Chrome 已经打开，程序会先询问是否关闭并重启一次；请允许后再继续。浏览器一般会恢复之前的标签页，但未提交的网页表单可能丢失。
- 采集通常需要 10 到 90 秒，期间可以取消任务。
- 如果窗口里没有登录抖音，请直接在该浏览器中扫码登录一次；完成登录后程序会继续等待并读取。
- 采集结束后浏览器会保持打开，不会自动关闭你的窗口。
- 程序不复制密码、书签或浏览历史。

不勾选浏览器模式时使用公开网页接口，未登录只能看到公开作品，遇到安全验证或接口变化也可能失败。

### 5. 下载作品

- 单击选择一条作品，Ctrl 或 Shift 可多选。
- 点击全选可选择全部作品。
- 点击下载选中开始下载。
- 列表状态会显示：待下载、下载中、已完成、已跳过、失败。

### 6. 输出文件

    下载目录/
      用户昵称_sec_uid后8位/
        2026-02-14/
          日期_时间_作品ID_标题.mp4
          同名 .mp4.json 元数据
        metadata.json

### 7. 常见问题

- 没有识别到 sec_uid：请复制用户主页完整链接，而不是只输入抖音号。
- 无法获取作品列表：改用浏览器模式，并手动完成登录或验证。
- 浏览器没有采集到作品：确认账号公开、视频公开、页面已加载，稍后重试。
- 下载失败：检查网络或稍后重试；已下载过的视频会自动跳过。
- 浏览器模式打不开：确认系统已安装 Edge 或 Chrome，并允许程序关闭后重新打开浏览器。

- 如果下载目录报 WinError 5 拒绝访问，工具会自动切换到程序目录下的抖音下载；也可以点击浏览选择 D 盘等可写目录。

- 关闭软件时，如果正在下载，程序会先取消任务并等待网络操作结束；浏览器窗口会保持打开。

## 登录与作品数量不一致

工具直接通过本机浏览器读取作品接口，会复用你真实 Edge/Chrome 中的抖音登录状态。如果浏览器窗口显示未登录，登录一次后即可看到该账号有权限访问的作品。

如果登录后作品数量仍少于手机端，通常是因为剩余作品属于仅自己可见、朋友可见、付费或审核中内容；这类内容不会通过公开采集返回。
