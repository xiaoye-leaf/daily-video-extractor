# 日常视频提取器（抖音 / 快手 / B站）
输入指定用户的抖音、快手或 B站主页链接，按日期筛选作品，并批量下载到按用户、日期分层的目录。

## 支持平台

- 抖音：`https://www.douyin.com/user/MS4wLjAB...`
- 快手：`https://www.kuaishou.com/profile/3x...`
- B站：`https://space.bilibili.com/123456/video`

快手和 B站读取需要勾选“使用本机浏览器登录态”。B站多P视频当前保存第一个分P。

> 仅供个人学习、备份自己的作品或经授权内容使用。请遵守抖音用户协议、版权和隐私规定；不要批量抓取、传播或商用他人内容。本工具不内置账号、Cookie 或任何媒体文件。

## 功能

- 用户主页 URL、分享链接或 `sec_uid`
- 日期筛选：今天、昨天、近 7 天、全部、自定义
- 作品列表、批量下载、实时进度、取消任务
- 支持普通视频、图文相册、实况照片（Live Photo）
- 图文作品保存为图片序列；实况照片同时保存图片和短视频
- 不再把图文的背景音乐误存成视频
- 下载目录：`用户昵称_sec_uid后8位/YYYY-MM-DD/`
- `.part` 临时文件、历史去重、每条视频 `.json` 元数据、`metadata.json`
- 浏览器模式直接使用你平时的 Edge/Chrome 窗口和登录状态
- 运行时只用 Python 标准库，无需安装其他软件包

### 快速读取

- 直接的用户链接会在本地识别，跳过资料预请求。
- 每次作品接口返回后立即继续滚动，不再固定等待 1.2 秒。
- 接口明确返回“没有更多”后约 0.25 秒结束。
- 选择今天、近 7 天等日期范围时，一旦读到范围之前的作品就提前停止。
- Windows 进程检测改用系统 API，减少启动、关闭浏览器时的等待。
- 浏览器启动后会检查本地读取组件的实际连接状态，避免“网页打开但组件未加载”。
- 如果 Edge 的启动加速复用了无扩展的后台进程，程序会自动关闭并重试，共最多 3 次。

## 环境要求

- Windows 10/11
- Python 3.10+（官方 Windows 安装包默认包含 Tkinter）
- 可选：PyInstaller（仅打包 exe 时需要，由 build.bat 自动安装；日常运行不需要）

## 快速开始

1. 安装 Python 3.10+，安装时勾选 Add python.exe to PATH。
2. 双击 run.bat，或执行：python douyin_daily.py
3. 在浏览器打开目标用户主页，复制地址栏链接，例如：
   https://www.douyin.com/user/MS4wLjAB...
4. 粘贴到工具中，选择日期，点击获取作品。
5. 勾选使用本机浏览器登录态。程序会使用你平时 Edge/Chrome 的登录状态；如果浏览器已经打开，会询问是否关闭并重启一次。

### 浏览器读取方式

程序会在本机启动一个临时读取桥（只监听 127.0.0.1，其他设备无法访问），并通过一个临时 Edge/Chrome 扩展，在你自己的浏览器窗口中读取抖音作品接口。

- 直接使用你平时的 Edge/Chrome 浏览器和抖音登录状态
- 不复制密码、书签或浏览历史
- 读取到的数据只发送到本机程序，不上传外部服务器
- 采集结束后浏览器保持打开，不会自动关闭你的窗口

每次使用浏览器模式时，请先保存网页中未提交的内容。如果 Edge/Chrome 已经打开，程序会弹窗询问是否关闭并重启一次；选择 "是" 即可。浏览器一般会恢复原来的标签页，但未提交的网页内容可能丢失。

如果窗口里没有登录抖音，直接在这个浏览器中扫码登录一次，程序会继续等待并读取。

### Edge/Chrome 已经打开怎么办？

点击获取作品后选择 "是"，程序会自动关闭并重新打开浏览器一次；原来的标签页一般会自动恢复。

如果提示无法关闭，请按 Ctrl+Shift+Esc 打开任务管理器，结束所有 msedge.exe 或 chrome.exe 进程；或在浏览器菜单中完全退出后重试。

### 只有抖音号怎么办？

抖音号不能稳定地直接转换成 sec_uid。请先在浏览器打开该用户主页，复制地址栏完整链接再粘贴。

## 命令行用法

平台参数：`--platform auto|douyin|kuaishou|bilibili`。
快手和 B站必须加 `--browser`；抖音模式下 `--browser` 推荐但不强制。

抖音：

    python douyin_daily.py --url "https://www.douyin.com/user/MS4wLjAB..." --platform douyin --date today --browser --download --out "D:\视频下载"

快手：

    python douyin_daily.py --url "https://www.kuaishou.com/profile/3x..." --platform kuaishou --date 7days --browser --download --out "D:\视频下载"

B站：

    python douyin_daily.py --url "https://space.bilibili.com/123456/video" --platform bilibili --date all --browser --download --out "D:\视频下载"

只列出作品时去掉 `--download`。`--date` 支持：`today`、`yesterday`、`7days`、`all`、`YYYY-MM-DD`。

        2026-02-14/
          日期_时间_作品ID_标题.mp4

Cookie 默认不保存；只有主动勾选保存 Cookie 才会写入本机。请勿分享 Cookie。

## 已知限制

- 抖音不是公开稳定 API，接口和风控随时可能变化。
- 不绕过登录、付费、隐私或访问权限。
- 私密作品、仅粉丝可见、已删除作品无法获取。
- 直播、付费内容、私密作品不在下载范围内。
- 无水印取决于接口实际返回地址，不保证所有作品都有。
- 请控制请求频率和下载量。

## 详细使用说明

### 1. 启动

推荐使用打包版，不需要安装 Python：

    dist\DouyinDailyExtractor\DouyinDailyExtractor.exe

也可以双击项目根目录的 run.bat，它会自动优先启动打包版。

请保留整个 dist\DouyinDailyExtractor 文件夹，不要只单独移动 exe。

### 2. 获取目标用户链接

在浏览器打开抖音网页版，进入目标用户主页，复制地址栏链接。链接通常形如：

    https://www.douyin.com/user/MS4wLjAB...

也支持能跳转到用户主页的分享链接。只有抖音号或昵称时，请先手动打开其主页再复制链接。
### 3. 获取作品

1. 把用户链接粘贴到用户链接输入框。
2. 选择下载目录。
3. 选择日期：今天、昨天、近 7 天、全部或自定义。
4. 勾选使用本机浏览器登录态（推荐）。
5. 点击获取作品。
6. 作品会显示在下方列表。

### 4. 浏览器模式

- 程序会直接调用本机已安装的 Edge/Chrome，打开你平时使用的浏览器窗口。
- 会在该浏览器中临时加载一个本地读取组件，等待抖音页面自己请求作品接口，再把结果发回工具。
- 本地读取组件只连接 127.0.0.1，读取到的数据不会上传到外部服务器。
- 因此可以直接复用你浏览器里已有的抖音登录、关注和可见权限。
- 如果 Edge/Chrome 已经打开，程序会先询问是否关闭并重启一次；请允许后再继续。浏览器一般会恢复之前的标签页，但未提交的网页表单可能丢失。
- 采集通常需要 10 到 90 秒，期间可以取消任务。
- 如果窗口里没有登录抖音，请直接在该浏览器中扫码登录一次；完成登录后程序会继续等待并读取。
- 采集结束后浏览器会保持打开，不会自动关闭你的窗口。
- 程序不复制密码、书签或浏览历史。

不勾选浏览器模式时使用公开网页接口，未登录只能看到公开作品，遇到安全验证或接口变化也可能失败。

### 5. 下载作品

- 单击选择一条作品，Ctrl 或 Shift 可多选。
- 点击全选可选择全部作品。
- 点击下载选中开始下载。
- 列表状态会显示：待下载、下载中、已完成、已跳过、失败。

### 6. 输出文件

    下载目录/
      用户昵称_sec_uid后8位/
        2026-02-14/
          日期_时间_作品ID_标题.mp4
          同名 .mp4.json 元数据
        metadata.json

### 7. 常见问题

- 没有识别到 sec_uid：请复制用户主页完整链接，而不是只输入抖音号。
- 无法获取作品列表：改用浏览器模式，并手动完成登录或验证。
- 浏览器没有采集到作品：确认账号公开、视频公开、页面已加载，稍后重试。
- 下载失败：检查网络或稍后重试；已下载过的视频会自动跳过。
- 浏览器模式打不开：确认系统已安装 Edge 或 Chrome，并允许程序关闭后重新打开浏览器。

- 如果下载目录报 WinError 5 拒绝访问，工具会自动切换到程序目录下的抖音下载；也可以点击浏览选择 D 盘等可写目录。

- 关闭软件时，如果正在下载，程序会先取消任务并等待网络操作结束；浏览器窗口会保持打开。

## 登录与作品数量不一致

工具直接通过本机浏览器读取作品接口，会复用你真实 Edge/Chrome 中的抖音登录状态。如果浏览器窗口显示未登录，登录一次后即可看到该账号有权限访问的作品。

如果登录后作品数量仍少于手机端，通常是因为剩余作品属于仅自己可见、朋友可见、付费或审核中内容；这类内容不会通过公开采集返回。
